# Code de conduite

Les échanges doivent être respectueux, factuels et ouverts à la critique des méthodes. Le dépôt sert à l’enseignement et à la description de données officielles.

Ne pas utiliser les contributions au projet pour promouvoir un parti, cibler des électeurs, réidentifier des personnes ou diffuser des coordonnées personnelles. Les erreurs doivent être corrigées avec une trace de provenance, sans modifier silencieusement les valeurs officielles.

Les responsables peuvent retirer un contenu qui enfreint ces principes. Les signalements peuvent être adressés au mainteneur par les moyens indiqués sur son profil GitHub; ne pas déposer d’informations confidentielles dans une issue publique.
